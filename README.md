# GitHub User Finder 🔍

A clean, responsive, and easy-to-use web application built with **HTML, CSS, and Vanilla JavaScript** that allows users to search for any GitHub profile and instantly view their profile details, repositories, followers, and bio.

## 🚀 Features

- **Real-time Search:** Fetch public GitHub profile data instantly using the official GitHub REST API.
- **Detailed Profile Info:** Displays user avatar, full name, username, bio, public repository count, followers, and following count.
- **Direct Profile Link:** Quick access button to open the searched user's original GitHub profile.
- **Error Handling:** Gracefully handles invalid usernames (404 errors) and network issues with user-friendly alerts.
- **Responsive Design:** Looks great and works smoothly on both desktop and mobile devices.

## 🛠️ Built With

- **HTML5** - Structure and layout
- **CSS3** - Styling and layout design
- **Vanilla JavaScript (ES6+)** - API handling and DOM manipulation
- **GitHub REST API** - Data source

## 💻 How to Run Locally

1. Clone or download this repository to your local machine.
2. Open the project folder.
3. Simply open the `index.html` file in any modern web browser (Google Chrome, Firefox, Edge, etc.).
